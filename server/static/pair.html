1 · How phones reach this laptop

Phones on other networks (mobile data, another Wi-Fi) connect out to this laptop, so they need an address they can reach. Same Wi-Fi works automatically. For anywhere else, expose port 8000 with a tunnel and paste its public URL here, for example cloudflared tunnel --url http://localhost:8000 (gives an https URL) or a Tailscale / VPS / router port-forward address.

Phones try these in order and switch automatically when they change networks:

Cloudflare relay (free, permanent address)

Laptop and phones both connect out to your Cloudflare Worker, so it works from any network on either side. Status: —

2 · Pair a phone

QR code

Phone connected by USB: press Pair via USB next to it below — done.

Phone somewhere else: install the Operator Companion app, then scan this QR code with the phone camera (or open the link on the phone). The app stores the addresses and the access token and stays connected in the background.
